# GitHub Portfolio Website

Personal portfolio website for The Vasait.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and dynamic year

## Before publishing

Update these values in `index.html`:

1. `The-Vasait` → your exact GitHub username.
2. LinkedIn URL.
3. Email address.
4. Each project's repository URL.
5. Project descriptions when your repositories become available.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

Create a repository such as:

```text
portfolio
```

Upload `index.html`, `style.css`, and `script.js`.

Then:

`Repository → Settings → Pages → Deploy from branch → main → / (root)`

GitHub will provide the published website URL.
